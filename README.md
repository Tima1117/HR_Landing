# CVortex — лендинг ИИ-автоматизации первичного найма

**Живая версия:** https://hr-landing-seven.vercel.app

Next.js 14 + TypeScript + Tailwind + **GSAP ScrollTrigger** + **Lenis** + framer-motion.

## Дизайн-направление

Взято из скилла `ui-ux-pro-max` для типа продукта **AI/Chatbot Platform**:
AI-Native UI + минимализм, паттерн лендинга **Interactive Product Demo**,
палитра «нейтральный + AI-фиолетовый #6366F1», минимум лишнего хрома.

## Что внутри

- **`ChatDemo`** — сердце лендинга. Продукт показывает себя сам: бот
  переписывается с кандидатом, печатает с задержкой, зацикливается. Это и есть
  паттерн Interactive Product Demo, а не картинка «как бы интерфейс».
- **`GridGlow`** — SVG-сетка со свечением за курсором. Основа — Modern Hero
  section с 21st.dev (uniquesonu): сетка перерисована программно вместо простыни
  `<rect>`, палитра переведена на индиго, слушатель мыши повешен на сам блок,
  а не на window.
- **Lenis + ScrollTrigger** — инерционный скролл, параллакс, пословное
  проявление заголовков, закреплённая секция с горизонтальной лентой шагов.
- Бенто-сетка возможностей с подсветкой за курсором.

## Принцип: контент не прячется за анимацией

У прежней версии этого лендинга **31 элемент навсегда застревал в `opacity: 0`** —
посетитель видел синий экран с одним логотипом. Поэтому здесь: наблюдателем
управляет сам framer (`whileInView`), скрытие снимается принудительно через
секунду, слова заголовков стартуют с непрозрачности 0.12, а мелкие числа не
анимируются вовсе. `prefers-reduced-motion` отключает инерцию, параллакс,
пиннинг и печать в демо.
